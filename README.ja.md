# mp4 Slicer

動画から連番画像を抽出し、画像をまとめて加工してPNG・WebP・GIFで保存するブラウザツールです。手持ちの画像・フォルダーからも始められます。素材の処理はブラウザ内で完結し、サーバーにはアップロードされません。

Page: https://yokazek.github.io/mp4-slicer/

[English Version (README.md)](README.md)

## ✨ 特徴

- **プライバシー保護**: すべての処理をローカルで実行。動画データは外部に送信されません。
- **高機能クロップ**: 
  - 自由指定のほか、アスペクト比プリセット（16:9, 4:3, 1:1, 9:16）に対応。
  - ドラッグ操作で直感的に範囲を指定可能。
- **精密な時間指定**: 
  - 視覚的なレンジハンドルで開始・終了地点を選択。
  - ミリ秒単位の直接入力による詳細指定も可能。
- **柔軟な間隔設定**: フレームの抽出間隔（例：0.5秒ごと、1.0秒ごと）を自由に設定。
- **共通の画像編集**:
  - 複数画像・フォルダーを自然順で読み込み、チェックで選択、矢印で並べ替え。
  - 各画像のサイズ維持、または共通サイズへの変更に対応。
  - 全体を収める・中央で切り抜く・伸縮、背景色・透明背景を指定。
  - PNG・WebP・GIFに共通の加工を適用。元画像は保持するため設定を変更してやり直せます。
  - 加工後の静止画・アニメーションを確認可能（圧縮・減色前の表示）。
- **GIF作成**:
  - 共通サイズ・背景色を使用。再生速度・ループ・色数・ディザリングを指定可能。
  - GIFの時間単位に合わせて再生間隔を10ms単位に丸めます。透明背景の出力はPNG・WebPのみです。
- **一括書き出し**: 
  - 書き出し前にプレビューで確認可能。
  - 選択した画像をPNGまたはWebPに変換し、順序付きファイル名でZIPに保存。
  - WebPはLossy／Lossless、Quality、Effortを指定可能。
  - WebP変換はWeb Workerで実行し、画面下部の固定プログレスバーで進捗を表示。
- **モダンなUI**: 
  - 洗練されたグラスモーフィズム・デザイン。
  - ダークモードとライトモードの切り替えに対応。
  - レスポンシブレイアウト。

## 🚀 使い方

1. 公開ページを開くか、このディレクトリで `python -m http.server 8765 --bind 127.0.0.1` を実行し、`http://127.0.0.1:8765/` を開きます（WebP用WorkerのためHTTPで利用）。
2. 共通の読み込みエリアへ動画、連番画像、または画像フォルダーをドロップします。「ファイルを選択」からも動画・画像を読み込めます。
3. 必要に応じてクロップ範囲や時間範囲を調整します。動画は指定範囲だけをループ再生し、終了時刻に達すると開始時刻に戻ります。一時停止後はその位置から再開します。
4. **「フレームを抽出」**で横スクロールのタイムラインを作成し、チェックと矢印で対象・順序を調整します。画像のクリックや表示位置スライダーで加工後プレビューを切り替えられます。再生中は現在のコマを強調し、画面外に進むと自動で追従します。「拡大」で詳細を確認できます。
5. 共通の加工設定を指定し、加工後プレビューを確認します。直下の「再生」でアニメーション確認、「前のコマ／次のコマ」で一時停止してコマ送りできます。「このフレームを書き出す」のチェックで除外・復帰でき、一覧のチェックと連動します。コマ送りは全画像、連続再生は選択画像が対象です。全選択・全解除はフレーム一覧の直上にあります。
6. 書き出し欄でPNG・WebP・GIFを選び、保存します。

連番画像から始める場合は画像・フォルダーを読み込み、直接編集・保存へ進みます。動画の抽出設定を変更した場合は案内が表示されます。再抽出すると選択・並び順はリセットされます。

## 動作確認

ローカルサーバーで `/tests/workflow.html` を開き、「検証を実行」をクリックします。生成した画像・動画を使ってPNG・WebP・GIF、ZIP、並べ替え、再抽出案内を検証します。既存のCDNライブラリを使うため初回読み込みには通信が必要です。

## 🛠️ 使用技術

- **HTML5 / CSS3**: パフォーマンスを重視したバニラ実装。
- **JavaScript (ES6+)**: コアロジックおよびCanvasを用いたフレーム抽出。
- **[JSZip](https://stuk.github.io/jszip/)**: クライアントサイドでのZIP生成。
- **[gifenc](https://github.com/mattdesl/gifenc)**: クライアントサイドでのGIF生成と減色。
- **[@jsquash/webp](https://github.com/jamsinclair/jSquash)**: libwebp（WebAssembly）によるWebPエンコード。
- **[Lucide Icons](https://lucide.dev/)**: クリーンでモダンなアイコンセット。
- **Google Fonts**: 視認性に優れた `Inter` フォントを採用。
